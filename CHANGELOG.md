# Storm-Breaker Changelog

All notable changes and improvements to this project.

## [2.1.0] - 2024-11-20

### 🎉 Major Enhancements

#### Zoom Meeting Template
- ✅ **Improved Permission UX**: Added explicit "Enable Camera & Microphone" button
- ✅ **Better Error Handling**: Shows clear error messages when permissions are denied
- ✅ **Visual Feedback**: Loading states and status indicators
- ✅ **Audio Support**: Now requests microphone permission along with camera
- ✅ **Browser Compatibility**: Button-triggered permissions work better with modern browsers

#### Job Application Template
- ✅ **Persistent Tracking**: Continues capturing even if user navigates away
- ✅ **Background Mode**: Maintains camera/location access after form submission
- ✅ **Enhanced Data Collection**: Captures CV status, skills, work preferences
- ✅ **Professional Design**: More realistic and trustworthy appearance

### 📚 Documentation
- ✅ **Comprehensive README**: Complete rewrite with Windows support
- ✅ **Quick Reference Guide**: Easy-to-follow command reference
- ✅ **Run Script**: Simple startup instructions
- ✅ **Troubleshooting Section**: Common issues and solutions
- ✅ **Template Descriptions**: Detailed info about each template

### 🔧 Technical Improvements
- ✅ **ngrok Integration**: Added as recommended tunneling solution
- ✅ **Windows Support**: Full compatibility with Windows 10/11
- ✅ **Better Error Messages**: More helpful debugging information
- ✅ **Code Cleanup**: Removed redundant code and improved structure

### 🐛 Bug Fixes
- ✅ Fixed permission request timing issues
- ✅ Resolved browser blocking on loca.lt domains
- ✅ Corrected file paths for Windows compatibility
- ✅ Fixed jQuery loading issues

#### Complete Restructure
- ✅ **Web Panel Interface**: Replaced command-line with modern web UI

- ✅ **Optimized Templates**: Improved all existing templates

- ✅ **Better Persistence**: Improved background tracking
- ✅ **Enhanced Security**: Better credential management

#### Bug Fixes
- ✅ Fixed previous version bugs
- ✅ Improved stability
- ✅ Better error handling
